Only worth running if round one showed PRF being refused. The first asks for the older hmac-secret by name instead of prf; they are the same machinery underneath, and an authenticator may answer to one spelling and not the other. The second drops the demand for a built-in authenticator, so a security key or a phone can answer — which tells you whether the refusal belongs to Hello specifically.
