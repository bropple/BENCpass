      Filling

      Recovery code

      Master password Re-wraps the vault key under a new password — no record is re-encrypted, your recovery code and fingerprint keep working, and other machines switch the first time you unlock them with the new password. Until a machine switches, it still opens with the old one, and so does any old backup file: changing the password does not rewrite history.

      Your data

      Export Writes a file with your passwords in plain text. That is what makes it a backup and what makes it dangerous: keep it somewhere you would keep the passwords themselves, and delete it when you are done. JSON keeps everything, including addresses; CSV keeps logins only, for handing to another program.
      Encrypted backup The whole vault, still encrypted, exactly as it is stored here. It opens with your master password, or with your recovery code if you enrolled one — a fingerprint will not open it, and is deliberately left out of the file. Its safety is your master password's safety: anyone holding it can guess at it offline for as long as they like, with nobody to notice and no lockout. A strong password makes this file useless to them; a guessable one makes it a copy of your passwords with a delay on it. This is the file BENCpass Rescue reads when this browser is the thing that broke. The Import button below cannot read it — it is sealed, and Import reads plain exports. To restore it, open it with BENCpass Rescue, export JSON from there, and import that.
      Import A file exported from BENCpass, Firefox, Chrome, Bitwarden or KeePass. Entries are added; nothing already here is replaced or overwritten.
